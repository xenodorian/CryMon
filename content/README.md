# content/

The game lives in these JSON files. Web imports them. Dreamcast bakes them.
Catalog and rules: [`../docs/CRYMON.md`](../docs/CRYMON.md).

| File | Owns |
|---|---|
| `species.json` | stats, moves, spells |
| `items.json` | bag/shop + effects |
| `maps.json` | ASCII maps, solids, tile art keys |
| `dialogue.json` | talk, intro, ending, speakers |
| `world.json` | warps, encounters, trainers, NPC scripts, formulas |
| `sprites.json` | art catalog |
| `logic.json` | shared rules both engines interpret |
| `audio.json` | songs + SFX |
| `save.json` | save blob layout |
