2. WHAT THE PROJECT IS
======================================================================
CryMon: a monster-catching RPG, one game with two runtimes.
  - content/*.json + public/sprites/ = the shared game (both engines).
  - src/game/ = web engine (TypeScript). Owned by Grok.
  - ports/dreamcast/ = Dreamcast port (C). Owned by Claude.
Pipeline (from CLAUDE.md):
  python3 tools/bake_content.py --content content --out ports/dreamcast/src
  python3 ports/dreamcast/tools/gen_sprites.py
  python3 tools/check_sync.py --strict
  make -C ports/dreamcast        (Docker image einsteinx2/dcdev-kos-toolchain:gcc-9)
Never hand-edit content_*.inc or sprites.h. If JSON and main.c disagree,
JSON wins.
