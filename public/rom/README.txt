CryMon
======

Web preview is the playable game.

Dreamcast CDI
-------------
Download CryMon.cdi (this folder). Open it in Flycast / Redream / a real
Dreamcast (burned CD-R or ODE).

Flycast: put CryMon.cdi in the games folder. VGA cable if you have one,
HLE BIOS on, Full Framebuffer Emulation on, Linear Interpolation off.

Built from ports/dreamcast against the shared content/ JSON and
public/sprites pack.

SNES, LÖVE, and SDL/R36S PortMaster ports were removed.
